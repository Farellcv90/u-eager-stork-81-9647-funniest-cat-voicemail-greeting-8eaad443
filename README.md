One voicemail greeting as if a cat recorded it — a dismissive, unbothered
cat napping in the cardboard box instead of the bed its human bought,
telling the caller to leave a message it has no intention of listening to.

Competition: https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443

## The entry (110 characters)

> "Meow. You've reached the cat. I'm napping in the box you bought me a bed for. Leave a message. I won't listen."

## How to run

```sh
python3 main.py
```

This validates the entry (1–120 characters of non-blank UTF-8 text),
writes it to `/output/entry.txt`, and prints the character and byte
counts. Standard library only — no dependencies.
